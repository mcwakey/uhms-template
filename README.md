# UHMS Frontend

## Run locally
- Web:
  - `npm install`
  - `npm run dev`
- Flutter:
  - `flutter pub get`
  - `flutter run`

## Conventions
- Branch naming: `feature/<short-desc>`, `bugfix/<short-desc>`, `chore/<desc>`
- Commit format: `<scope>: <short summary>`
- Use Copilot Plan Agent for consistent code generation.
